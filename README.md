# CCNA Final Project - Enterprise Network

## 📘 Description

This project presents the design and implementation of a **multi-site enterprise network infrastructure** for a fictional company named **AI-TECH**, operating two geographically separated branches: **Afek** and **Tel Aviv**.

The network was fully designed and implemented using **Cisco Packet Tracer**, following **CCNA-level enterprise best practices**.  
It is based on a hierarchical architecture (Access, Distribution, Core), includes VLAN-based segmentation, dynamic routing between sites, centralized network services, and multiple security controls using ACLs and port security.

The project demonstrates end-to-end planning, configuration, validation, and documentation of a scalable and secure enterprise network.

---

## 🛠️ Technologies Used

- **Cisco Packet Tracer**
- **Cisco IOS (Routers & Catalyst 2960 Switches)**
- **VLANs & Trunking (802.1Q)**
- **Router-on-a-Stick**
- **OSPF (Single Area – Area 0)**
- **DHCP (Server-based & Router-based)**
- **DNS, Email (SMTP/POP3), Web Services**
- **SSH (Secure Device Management)**
- **Port Security (Sticky MAC, Restrict mode)**
- **Extended Access Control Lists (ACLs)**
- **WAN Point-to-Point Connectivity**

---

## ⭐ Project Highlights

- Hierarchical enterprise network design using **Access, Distribution, and Core layers**
- Department-based **VLAN segmentation** across two sites
- **Dynamic routing with OSPF** over a dedicated WAN link
- Centralized and distributed **DHCP implementation**
- Dedicated **Management Network** with static IP addressing
- Secure device management using **SSH only**
- Fine-grained traffic control using **Extended ACLs**, including:
  - Guest isolation from internal networks
  - Email service restrictions
  - ICMP (ping) allowed only for the IT department
- Deployment of centralized **DNS, Email, and Web services**
- Full end-to-end testing and validation
